# SWYNEX Exploratory Data Analysis

## Project Overview

This project was completed as part of the SWYNEX Data Analyst Internship.

The objective was to perform Exploratory Data Analysis (EDA) on the cleaned Titanic dataset and identify useful trends, patterns, and insights.

## Analysis Performed

The following analyses were performed using Python:

- Dataset overview and descriptive statistics
- Overall survival rate analysis
- Survival rate by gender
- Survival rate by passenger class
- Age group distribution
- Fare distribution and outlier analysis
- Family size and survival analysis
- Data visualization using charts

## Key Insights

### 1. Overall Survival
The overall survival rate was approximately **38.4%**.

### 2. Survival by Gender
Female passengers had a survival rate of approximately **74.2%**, compared with **18.9%** for male passengers.

### 3. Survival by Passenger Class
First-class passengers had the highest survival rate at approximately **63.0%**.

Second-class passengers had a survival rate of approximately **47.3%**, while third-class passengers had the lowest at approximately **24.2%**.

### 4. Age Distribution
The largest age group was **Young Adults**, with **447 passengers**.

### 5. Fare Distribution
The average fare was approximately **32.20**, while the maximum fare was **512.33**.

There were **53 passengers** who paid a fare above 100, indicating the presence of high-fare outliers.

### 6. Family Size and Survival
Passengers travelling in small to moderate-sized families generally showed higher survival rates than passengers travelling alone or in very large families.
